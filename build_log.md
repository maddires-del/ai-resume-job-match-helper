## Improvements After Project 1 Feedback

Based on feedback from Project 1, I made Project 2 more specific, more agentic, and more evaluated.

Changes made:
- Added a Data Science and Generative AI internship focus.
- Added a skill framework for grounding.
- Added multiple agent actions instead of only one resume analysis task.
- Added five evaluation cases, including a weak resume case and a failure case.
- Used more descriptive commit messages to show iteration.

## Agentic Design Decision

The app is agentic because the user selects an action and the system changes its behavior based on that action.

The agent can:
- analyze job fit
- improve resume bullets
- write recruiter messages
- generate interview prep
- create application checklists

This makes the system more autonomous than a simple chatbot because it performs different application-support tasks.

## Lesson Learned

From Project 1, I learned that a working app is not enough. The project also needs deeper grounding, better evaluation, and clearer documentation of prompt decisions.
